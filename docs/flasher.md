# Web Firmware Flasher

Flash the iown-homecontrol firmware directly to your microcontroller from your web browser using Web Serial.

> [!NOTE]
> Web Serial requires a Chromium-based web browser such as **Google Chrome**, **Microsoft Edge**, **Brave**, or **Opera**. Safari and Firefox are currently unsupported.

## Heltec WiFi LoRa 32 V3

Connect your Heltec V3 board via USB and click **Install** below:

<script type="module" src="https://unpkg.com/esp-web-tools@10/dist/web/install-button.js?module"></script>
<esp-web-install-button manifest="../firmware/heltec_wifi_lora_32_V3/manifest.json"></esp-web-install-button>

## Flashing Instructions

1. Connect your microcontroller to your computer using a USB data cable.
2. Click the **Install** button above.
3. Select your microcontroller's serial port from the browser prompt and click **Connect**.
4. Follow the on-screen steps to flash the firmware.
